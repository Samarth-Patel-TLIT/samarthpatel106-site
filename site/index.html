How I work

Change carefully, automate the repeats, write it down

Controlled change

Pre-checks before, validation after, and maintenance windows agreed with application and server owners. That is how the vSphere upgrade and the PowerStore migration ran.

Automate the repeats

Patching, packages, users, sudo and service checks live in Ansible playbooks, Bash and PowerShell, so every server gets built and maintained the same way.

Leave it documented

SOPs, runbooks, and rack and network diagrams, so whoever is on call next is not guessing.
